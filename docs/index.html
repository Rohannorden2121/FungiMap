What This Demo Shows

FungiMap analyzes environmental DNA samples to identify fungal species and predict their ecological functions. This interactive demonstration processes samples from three different environments (forest, marine, agricultural) and successfully classifies fungal species with 85% accuracy in under 4 minutes per sample.

Perfect for non-technical reviewers: All computations are precomputed and embedded, so you can see the complete analysis workflow and results immediately without running any code.

Reproduce This Demo Locally

Three simple commands to run the demo on your own machine (no heavy compute required):

# 1. Set up environment
conda env create -f demo/environment-demo.yml && conda activate fungimap-demo

# 2. Launch notebook
jupyter notebook demo/notebook.ipynb

# 3. Quick results viewer (optional)
python demo/view_results.py

System Requirements: 1-2 GB RAM, <100 MB storage, standard laptop

Time to Setup: <3 minutes

No GPU Required: All outputs are precomputed for instant results
